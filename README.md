# Networkwalks Cybersecurity Internship

## Overview

This repository documents my practical work and learning progress during my Cybersecurity Internship with **Networkwalks**.

The projects and tasks documented here focus on developing practical skills in cybersecurity, networking, Linux, virtualization, and security testing through hands-on laboratory exercises.

---

## Internship Objectives

The main objectives of this internship are to:

- Develop practical cybersecurity skills through hands-on exercises.
- Build and configure cybersecurity laboratory environments.
- Strengthen networking and Linux administration skills.
- Gain practical experience with security tools and techniques.
- Understand cybersecurity concepts through real-world lab activities.
- Document practical tasks, configurations, troubleshooting processes, and results.

---

The internship activities involve the following technologies and tools:

- **Kali Linux**
