# 🛡️ Networkwalks Cybersecurity Internship

## Overview

This repository documents my practical cybersecurity internship journey with **Networkwalks**, including hands-on laboratory tasks, configurations, and learning outcomes.

## Weeks 1–2

The first two weeks focused on:

* **Week 1:** Setting up a cybersecurity lab using VirtualBox and Kali Linux, configuring networking, and performing basic network scanning.
* **Week 2:** Footprinting and reconnaissance using cybersecurity tools to gather information about domains and networks.

The internship combines **cybersecurity, networking, Linux, virtualization, and practical security tools** through hands-on exercises.

## Tools & Technologies

* Kali Linux
* Oracle VirtualBox
* Networking & TCP/IP
* Linux Command Line
* Nmap / Zenmap
* Maltego
* Virtual Machines

More practical tasks and technologies will be added as the internship progresses.
